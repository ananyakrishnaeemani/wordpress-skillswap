# SkillSwap – Peer-to-Peer Learning Platform (WordPress)

SkillSwap is a WordPress-based platform where users can submit, discover, and rate skills shared by the community.

## 📂 Contents

- `themes/skillswap-theme/` – Custom theme with homepage and post listing
- `plugins/skill-post-type/` – Registers custom post type: Skill
- `plugins/skill-rating-plugin/` – Enables AJAX star rating for skills
- `plugins/wp-user-frontend/` – (Optional) Used for frontend submissions
- `plugins/wp-staging/` – (Optional) Used for backups (if customized)

## 🔧 Setup

1. Clone the repo into your local WordPress install
2. Copy theme and plugin folders to `/wp-content/`
3. Activate theme and plugins via WordPress Admin

## 💡 Features

- Guest/Logged-in skill submissions
- Custom post type and taxonomy
- Skill ratings
- Responsive design
